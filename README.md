# SE新手村入门任务清单

有好奇的同学会问了，“为什么根目录里边没有‘任务1’呀”，当你能看到这行文字，说明你已经完成了任务1，Congratulations！



## 任务1

既然选择了SE软件方向，在平时的训练备赛过程里难免会遇到网络的问题，所以请务必保持一个稳定的网络连接环境，例如稳定访问github并且能够拉取文件到本地  



## 任务2 Ubuntu虚拟系统搭建

Linux系统是水下机器人主控的主要开发环境，因此需要你们能够最起码学会使用一些简单的命令   

请你在自己的电脑上部署虚拟机并完成安装Ubuntu系统工作（详情查看‘任务2.md’）  



## 任务3 ROS2初步了解

安装好虚拟机和系统之后，在ubuntu里下载并配置ROS2，运行turtle功能包程序（详情查看‘任务3.md’）
